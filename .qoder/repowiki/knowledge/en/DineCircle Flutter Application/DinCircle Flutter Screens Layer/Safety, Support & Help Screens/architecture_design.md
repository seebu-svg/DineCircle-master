Three sibling screen packages under `lib/screens/` with a clear dependency direction: `help/help_screen.dart` is the top-level hub that navigates into `safety/` and `support/` screens; `safety/` contains the reusable block confirmation helper (`safety_actions.dart`) plus per-feature screens (`blocked_users_screen.dart`, `my_reports_screen.dart`) and the shared report bottom sheet (`report_sheet.dart`); `support/feedback_form_screen.dart` is an independent form. All screens are Riverpod `ConsumerWidget` / `ConsumerStatefulWidget`s that read state via `ref.watch` on providers from `providers/safety_provider.dart` and mutate through `safetyRepositoryProvider`, never calling HTTP directly. Cross-cutting UI primitives come from `widgets/data_view.dart` (list + empty/retry shell) and `theme/app_*` for spacing/colors/text styles. The module has no internal sub-packages — it is a flat collection of single-responsibility screens sharing the same provider/theme/widget surface.
