Every test file sets `GoogleFonts.config.allowRuntimeFetching = false` in `setUp` and manually configures `tester.view.physicalSize` / `devicePixelRatio` (typically 1080×2400 at DPR 3) because the default Flutter test viewport (800×600) triggers layout warnings. Overflow-sensitive tests additionally override `FlutterError.onError` to capture `A RenderFlex overflowed` messages rather than letting them pass silently.
