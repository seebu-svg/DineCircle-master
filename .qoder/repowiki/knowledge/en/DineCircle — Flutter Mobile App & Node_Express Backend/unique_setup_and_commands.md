Server: `npm run dev` (tsx watch src/server.ts), `npm run start`, `npm run db:schema` / `db:seed` / `db:reset` / `db:check`, `npm test` runs typecheck + unit + integration suites. Requires `.env` (see `.env.example`) plus `supabase-ca.pem` for TLS to Supabase. Flutter: standard `flutter pub get` / `flutter run`; Android build via `android/build.gradle.kts`, iOS via `ios/Runner.xcworkspace`.
